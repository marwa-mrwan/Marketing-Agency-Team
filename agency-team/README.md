# فريق الوكالة المحفوظ

الإصدار: 1.1 — 2026-11-12. النطاق: هذا المشروع والجلسات التي تقرأ تعليماته؛ ليس إعدادًا عامًا لبروفايل ZadLoop.

## الاستخدام
قل: «استخدمي الفريق المحفوظ لهذا العميل: [الموقع]، المطلوب: [...]، تحليل فقط / مسودة تنفيذ». يقرأ Lead تعريفه ثم يستدعي الأدوار المناسبة. يمكن طلب «متخصص SEO فقط» أو «مراجعة مستقلة». لا تحتاج إلى إنشاء Custom GPT أو Claude Project.

التعريفات مستندات تعليمات وليست Agents مسجلين في واجهة التطبيق. لا توجد هنا آلية تسجيل تلقائي مؤكدة أو ربط إلزامي بموديل. تستمر التعريفات على القرص، بينما يبدأ أعضاء الفريق داخل كل جلسة. إن لم تُحمّل تعليمات المشروع تلقائيًا، اطلب قراءة [AGENTS.md](<../AGENTS.md>) صراحة. لا تفترض أن نسخ الحزمة إلى مشروع آخر يتيح نفس الحسابات أو الأدوات.

## الخريطة
- `roles/lead.md`: توزيع العمل، الاعتماد، التسليم.
- `roles/seo.md`: استراتيجية البحث والمحتوى.
- `roles/ads.md`: الإعلانات المدفوعة.
- `roles/technical.md`: تشخيص تقني ومعايير قبول.
- `roles/developer.md`: تنفيذ WordPress أو Custom بعد اكتشاف المنصة.
- `roles/reviewer.md`: مراجعة مستقلة؛ يستدعى عند الحاجة.
- `roles/laravel.md`: متخصص Laravel ضمن Custom/Developer.
- `roles/infrastructure.md`: سيرفرات واستضافة؛ يستدعى عند وجود حاجة فعلية.
- `skill-routing.md`: اختيار المهارات والأدوات.
- `templates.md`: سياق العميل، المهمة، الأدلة والتسليم.
- `review-notes.md`: منشأ النسخة العامة وسياسة التحديث.
- [دليل الإعداد](<../README.md>) و[مصادر المهارات](<../SKILLS.md>): النقل إلى بيئة جديدة.

## التشغيل المحلي
اتبع [local-workflow.md](<local-workflow.md>) لاكتشاف القدرات واعتماد المسار. لا موافقات موروثة من مساحة إعداد الحزمة. [قالب الدفتر الفارغ](<templates/tasks.example.json>) ليس سجل تشغيل فعليًا؛ Lead ينشئ سجله الخاص خارج الحزمة العامة، ولا ينطلق عمل عند فتح المشروع.

## الموديلات
الدور مستقل عن Agent/provider/model. قبل تشغيل أي دور، يسأل Lead المستخدم ليحدد Agent له وفق بوابة الاختيار في AGENTS.md؛ لا يوجد توريث تلقائي دون موافقة. افحص دعم الاختيار في أداة الفريق نفسها، ولا تغيّر إعدادات البروفايل أو المزودين تلقائيًا. يمكن اقتراح خيارات متاحة دون تشغيلها؛ لا تدّع أفضلية أو اتصالًا ناجحًا بناءً على الاسم فقط.

## الحدود
تسرد خريطة skill-routing.md أسماء wordpress-router ومهارات WordPress المتخصصة لاستخدام Developer عند توفرها في كتالوج المضيف. ظهورها لا يثبت جاهزية runtime أو اتصال موقع؛ التحقق أثناء المهمة. تعريف Infrastructure محلي، ولا يدّعي تثبيت مهارة سيرفرات أو استيراد مكتبة agency-agents. الربط تعليمات تشغيل صريحة: المساعد يحمّل skill المطلوبة فعلًا، وليس تسجيلًا آليًا أو hook في التطبيق.

لا تحمل كل المهارات أو المرفقات في كل تشغيل. هذه الحزمة تعليمات تشغيلية منقحة، وليست إعادة توزيع للمهارات أو المرفقات. لا توجد عمليات حية على العملاء أو تغييرات WordPress/Ads ضمن إعداد هذه النسخة العامة.

Measurement — متخصص القياس: تخصص مساعد عند الحاجة بتعليمات صريحة واختيار مستخدم مستقل، وليس عضوًا تلقائيًا. ملفات qa وimplementation القديمة روابط توافق لا أعضاء إضافيون.
