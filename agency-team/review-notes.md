# منشأ الحزمة وسياسة التحديث

هذه نسخة عامة من تعليمات تشغيل فريق تسويق على مستوى المشروع. أُبقيت تعريفات الأدوار والحوكمة وخريطة المهارات، وحُذفت تفاصيل مراجعات المرفقات والسياق الداخلي. لا تتضمن الحزمة ملفات عميل أو مرفقات أو أسرارًا أو تثبيتات Skills.

## مبادئ التحرير
- الفحص قبل السؤال، وأقل عدد كافٍ من المتخصصين.
- التحليل للقراءة فقط؛ التنفيذ الحي بخطة واعتماد محددين، واختبارات وrollback.
- اختلاف GSC وGA4 يستلزم فهم التعريفات، لا اختلاق سبب أو تعطيل كل العمل.
- لا يُعامل paid/organic overlap هدرًا تلقائيًا، ولا يُوعد بعائد أو ترتيب أو citations.
- ظهور صفحتين لاستعلام لا يثبت cannibalization؛ صحة Schema.org لا تضمن ميزة Google.
- أسماء Skills أو أدوات في المستندات لا تثبت التثبيت أو الاتصال أو الصلاحية.
- اكتشاف المنصة والإصدارات عند العمل، وحماية تغييرات المستخدم والخصوصية ونطاق العميل.

## المصادر والحقوق
راجع [مصادر المهارات](<../SKILLS.md>) للروابط العامة والمهارات المحلية التي لم يثبت لها مصدر عام. لا يُعاد توزيع كود أو نص المهارات الخارجية هنا. تظل تراخيص وحقوق المصادر الخارجية سارية؛ لم تُضف رخصة نيابة عن مالك الحزمة.

## سياسة التحديث
لكل ادعاء متغير: source URL + passage + retrieved_at + last_verified + review_due + owner. تُختار نافذة المراجعة حسب المخاطرة. السياسة والـAPI والأهلية تعاد قبل التنفيذ الحي. إذا فشل التحقق، يظل الادعاء provisional ويتوقف القرار المعتمد عليه؛ تاريخ الملف ليس دليل حداثة.

مصادر مرجعية، وليست ادعاء تحقق شامل من محتواها:
- https://developers.google.com/search/docs
- https://status.search.google.com/
- https://support.google.com/adspolicy/
- https://developer.wordpress.org/apis/security/

## حدود التحقق
فحص بنية الملفات لا يثبت جودة نتائج الموديلات أو auto-loading أو تشغيل WordPress أو Ads أو Laravel أو أي تكامل خارجي. لا تسجيل تلقائي لأعضاء دائمين، ولا تعديل بروفايل، ولا تثبيت Skills، ولا اتصال حسابات، ولا عمليات حية على العملاء ضمن هذه الحزمة.
