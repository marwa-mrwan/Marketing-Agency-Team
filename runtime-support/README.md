# نسخة إنقاذ Agent Teams — ليست MCP ولا تطبيقًا مستقلًا

هذه نسخة مرجعية من **الحزم الأربع المثبتة فعلًا** في ZadLoop `0.10.3` على Linux، بإصدار معلن `0.2.2-rc.1`، جُمعت في 2026-11-16. تحفظ التشغيل والأدوات والواجهة وحزمة التفعيل؛ لا تحفظ حسابات أو جلسات أو إعدادات مستخدم.

**الحد الحاسم:** الحزم تعتمد على محرك DSH و`dsh-base` وتخزين الجلسات ومزودي subagents وواجهات العميل. ليست برنامجًا مستقلًا، وليست نسخة كاملة من ZadLoop. لا تكفي وحدها إذا حُذفت هذه الخدمات أو تغيرت واجهاتها. لا يوجد اختبار هنا يثبت استعادة الميزة في إصدار مستقبلي؛ لا تسمِّها standalone أو one-click restore. الغرض حفظ الكود المطابق كأساس لإعادة التفعيل/الترحيل بواسطة مطور، لا وعد بتوافق تلقائي.

- `snapshots/tool-agent-team-0.2.2-rc.1.tar.gz`: الأدوات التسع الأصلية.

- [NOTICE.md](<NOTICE.md>) و[MIT](<licenses/DeepSeek-MIT.txt>): الترخيص والمنشأ وحدود نسبة النسخة المحلية إلى npm.
- [doctor.py](<doctor.py>): فحص offline للسلامة، ومقارنة اختيارية مع runtime آخر للقراءة فقط؛ لا ينفذ JavaScript ولا يثبّت شيئًا.
- [RESTORE.md](<RESTORE.md>): خطوات التشخيص والاستعادة المشروطة واختبار القبول والرجوع.

الأدوات المحفوظة: `spawn_teammate`, `send_message`, `list_agents`, `wait_agent`, `interrupt_agent`, `team_task_create`, `team_task_list`, `team_task_get`, `team_task_update`.

## الفحص الآمن

من جذر المستودع، باستخدام Python 3.9+ بلا dependencies أو شبكة:

```bash
python3 runtime-support/doctor.py
```

للمقارنة مع نسخة runtime مفكوكة على جهاز آخر:

```bash
python3 runtime-support/doctor.py --runtime /path/to/app.asar.unpacked/runtime
```

التطابق يعني تطابق الملفات المفحوصة فقط، لا ثبوت تمكين الميزة أو عمل الواجهة أو اتصال الموديل. mismatch أو missing لا يُصلح تلقائيًا. اختلاف المنصة أو build أو dependency يحتاج مراجعة، وليس إذنًا للنسخ فوق التطبيق.

## ما الذي يلزم لضمان استعادة مستقلة؟

يلزم أيضًا حفظ installer موثوق كامل لنفس إصدار التطبيق والمنصة، خارج بيانات المستخدم، والتحقق من ترخيص توزيعه وبصمته؛ أو بناء وتشغيل توزيع مستقل متوافق من DSH مع كل تبعياته واختباره في بيئة منفصلة. **لم تُجمع هذه النسخة الكاملة هنا.** لا توجد في هذه الحزمة أسرار أو OAuth أو profile أو tokens؛ إعادة ربط الحسابات تحتاج إذنًا منفصلًا.

اختيار Agent/model لكل دور يظل خاضعًا لدعم المضيف. `spawn_teammate` المحفوظ لا يقبل provider/model لكل استدعاء؛ إعدادا `freshProvider` و`forkProvider` هما مزودا إنشاء subagent، لا اختيار LLM لكل دور. لا تزعم أن التعليمات تضيف هذا الدعم.
